Сутності:
1) Athlete:
    uuid id PK - унікальний ідентифікатор
    string name - ім'я спротсмена
    uuid current_program_id FK - ідентифікатор поточної програми

2) Program:
    uuid id PK - унікальний ідентифікатор
    string name - назва програми
    uuid trainer_id FK - ідентифікатор тренера(у разі якщо програма не є загальною, а написана тренером)

3) Workout:
    uuid id PK - унікальний ідентифікатор
    string name - назва тренування(на яку групу м'язів)
    uuid program_id - ідентифікатор програми

4) Exercise:
    uuid id PK - унікальний ідентифікатор
    string name - назва вправи
    string description - опис вправи(робити у положенні сидячи на наступному тренажері тощо)

5) Workout_Item:
    uuid id PK - унікальний ідентифікатор
    uuid exercise_id FK - ідентифікатор вправи
    uuid workout_id FK - ідентифікатор тренування
    int exercise_order - порядковий номер вправи
    int min_reps - мінімальна кількість повторів
    int max_reps - максимальна кількість повторів
    int sets - кількість підходів

6) Program_Item:
    uuid id PK - унікальний ідентифікатор
    uuid program_id FK - ідентифікатор програми
    uuid workout_id FK - ідентифікатор тренування
    int workout_order - порядковий номер тренування
    uuid trainer_id FK - ідентифікатор тренера(у разі якщо тренування з тренером)

7) Trainer:
    uuid id PK - унікальний ідентифікатор
    string name - ім'я тренера

8) Tariff:
    uuid id PK - унікальний ідентифікатор
    string name - назва програми
    int period - кількість днів
    int price - ціна

9) Subscription:
    uuid id PK - унікальний ідентифікатор
    uuid tariff_id FK - ідентифікатор тарифу
    uuid person_id FK - ідентифікатор людини офрмила підписку
    Date start_date - дата початку дії програми
    bool isPaid  - чи оплачено
    

Зв'язки:
    Кожен відвідувач може мати лише одну програму тренувань у конкретний момент часу , бо програма орієнтована на одну активність , а саме тренажерний зал, одну програму може використовувати декілька відвідувачів

    Кожна програма містить декілька тренувань та одне тренування може перевикористовуватися у декількох програмах

    Одне тренування містить декілька вправ та одна вправа може міститися у декількох програмах
