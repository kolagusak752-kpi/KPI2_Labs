Сутності:
1) Athlete:
    uuid user_id FK PK - ідентифікатор юзера
    string name - ім'я спротсмена
    uuid current_program_id FK - ідентифікатор поточної програми

2) Program:
    uuid id PK - унікальний ідентифікатор
    string name - назва програми
    uuid trainer_id NULL FK - ідентифікатор тренера(у разі якщо програма не є загальною, а написана тренером)

3) Workout:
    uuid id PK - унікальний ідентифікатор
    string name - назва тренування(на яку групу м'язів)

4) Exercise:
    uuid id PK - унікальний ідентифікатор
    string name - назва вправи
    string description - опис вправи(робити у положенні сидячи на наступному тренажері тощо)

5) Workout_Item:
    uuid id PK - унікальний ідентифікатор
    uuid exercise_id FK - ідентифікатор вправи
    uuid workout_id FK - ідентифікатор тренування
    int exercise_order - порядковий номер вправи
    int min_reps - мінімальна кількість повторів
    int max_reps - максимальна кількість повторів
    int sets - кількість підходів

6) Program_Item:
    uuid id PK - унікальний ідентифікатор
    uuid program_id FK - ідентифікатор програми
    uuid workout_id FK - ідентифікатор тренування
    int workout_order - порядковий номер тренування

7) Trainer:
    uuid user_id PK FK - ідентифікатор юзера
    string name - ім'я тренера

8) Tariff:
    uuid id PK - унікальний ідентифікатор
    string name - назва програми
    int period - кількість днів
    int price - ціна

9) Subscription:
    uuid id PK - унікальний ідентифікатор
    uuid tariff_id FK - ідентифікатор тарифу
    uuid user_id FK - ідентифікатор людини офрмила підписку
    Date start_date - дата початку дії програми
    bool isPaid  - чи оплачено

10) User:
    uuid id PK - унікальний ідентифікатор
    string email NULL - пошта користувача
    string phone_number - номер телефона
    string hashed_password - пароль
    bool isTrainer - чи тренер
    bool isAthlete - чи атлет

11) Workout_Session:
    uuid id PK - унікальний ідентифікатор
    uuid workout_id FK - ідентифікатор тренування, яке користувач робить
    uuid trainer_id NULL FK - ідентифікатор тренера(у разі якщо тренування з тренером)
    int price - ціна тренування(у разі якщо тренування з тренером)
    bool isPaid NULL - чи оплачено(у разі якщо з тренером)
    timestamp date - коли відбулося тренування

12) Workout_Session_Exercise:
    uuid id PK - унікальний ідентифікатор
    uuid workout_session_id FK - ідентифікатор сесії тренування
    uuid exercise_id FK - ідентифікатор вправи
    
13) Workout_Session_Set
    uuid id PK - унікальний ідентифікатор
    uuid workout_session_exercise_id FK - ідентифікатор вправи конкретного тренування
    int order - порядковий номер підходу
    float weight - вага
    int reps - кількість повторів



    

Зв'язки:
    Користувач може бути або тренером або атлетом, зв'язок один до одного

    Кожен відвідувач може мати лише одну програму тренувань у конкретний момент часу, а одна програма тренувань може використовуватись для багатьох відвідувачів

    Кожен відвідувач може мати лише одну підписку або не мати її взагалі у випадку пробного тренування, підписка може мати одни й тільки один тариф

    Кожна програма містить декілька тренувань та одне тренування може перевикористовуватися у декількох програмах

    Одне тренування містить декілька вправ та одна вправа може міститися у декількох програмах

    Сесія тренування може містити тільки одне тренування на виконання, одно виконувача та тренера(якщо тренування з ним)

    Сесія тренування містить усі вправи які були виконані від 0 до багатьох, усі виконані на тренуванні вправи містять підходи від 0 до багатьох
